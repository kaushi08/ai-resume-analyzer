# 🚀 AI Resume Analyzer

An AI-powered Resume Analyzer built using Python and Streamlit that evaluates resumes against job descriptions using NLP and Machine Learning techniques.

---

## 📌 Features

- ATS Resume Score
- Skill Extraction
- Missing Skill Detection
- Resume Suggestions
- PDF & DOCX Support
- Analytics Dashboard
- Resume Analysis History

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- NLP
- SQLite
- Pandas
- PyPDF2

---

## 📂 Project Structure

```text
resume_analyzer/
│
├── app.py

├── requirements.txt

```

---

## ▶️ Run Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run application:

```bash
streamlit run app.py
```
